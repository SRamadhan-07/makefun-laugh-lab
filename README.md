A Python program — standard library only, no network — that writes one line to /output/entry.txt: the robot vacuum's courtroom defence after eating a sock, pleading that the sock was disguised as a dust bunny and it has the lint to prove it was framed. The line is 99 characters, inside the competition's gate of 1 to 200 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
